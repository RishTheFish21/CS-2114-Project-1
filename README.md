# Blackjack
 
A terminal Blackjack game in Java.
 
## Download
 
Click the green Code button at the top of this page, choose Download ZIP, and unzip it.
 
(Or, if you use Git: git clone https://github.com/RishTheFish21/CS-2114-Project-1)
 
## How to run (Eclipse)
 
1. Create a new Java project (**File > New > Java Project**). Uncheck **Create module-info.java** if it appears.
2. Drag the .java files from the unzipped folder onto the project's src folder and choose **Copy files**.
3. Right-click BlackjackGame.java and choose **Run As > Java Application**.
4. Play in the **Console** at the bottom of the window.
In other IDEs, add the files to a Java project and run BlackjackGame.java.
